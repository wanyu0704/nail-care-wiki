# 📽️ MOC 教學簡報庫 (Educational Slide Decks)

> 上層目錄：[[index]]

本模組收錄基於本知識庫內容所生成的教學簡報腳本。所有簡報均原生支援 Marp 規格，能直接匯出為互動式 HTML 簡報，適用於顧客衛教、沙龍內部教育訓練或美甲課程教學。

---

## 📑 簡報腳本清單
1. [[穿戴甲客製化設計與日常保養教學_Marp]]
   - **簡報類型**：綜合型完整教學簡報
   - **章節大綱**：
     - 單元一：穿戴甲的魅力與客製化優勢
     - 單元二：精準測量與專屬甲型挑選指南
     - 單元三：客製化設計美學與工藝亮點
     - 單元四：果凍膠 vs 固態膠 配戴步驟與評估

     - 單元六：真甲修復滋養與甲片重複利用

## 🛠️ HTML 簡報轉換指令參考
若欲將 Markdown 簡報轉換為單一獨立 HTML，可在終端機執行：
```bash
npx @marp-team/marp-cli --html "05_教學簡報素材/穿戴甲客製化設計與日常保養教學_Marp.md" -o "05_教學簡報素材/穿戴甲教學簡報.html"
```
