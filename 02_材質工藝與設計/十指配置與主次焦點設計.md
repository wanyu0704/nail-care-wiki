# 十指配置與主次焦點設計

一套精緻的客製穿戴甲，不能十指全滿，也不能十指平淡。合理的視覺焦點流動，是穿戴甲設計的高級感來源。

---

## 1. 焦點層級分工

```mermaid
flowchart LR
    A["👑 主焦點 (食指 / 無名指)<br>精緻手繪 / 油畫 / 3D浮雕"]
    B["✨ 次焦點 (拇指 / 中指)<br>高透貓眼 / 極細金邊"]
    C["🍃 陪襯指 (小指)<br>簡約跳色 / 輕透微珠光"]
    
    A --- B --- C
```

1. **主焦點（通常落於食指或無名指）**：
   - 負責吸引第一眼目光。
   - 配置最複雜的手繪圖案、立體油畫、精緻排鑽或特殊 3D 浮雕造形。
2. **次焦點（通常落於大拇指或中指）**：
   - 呼應主焦點，但不過度搶戲。
   - 配置 [[貓眼膠光澤與磁吸技巧|透亮貓眼]]、暈染光環或 [[立體裝飾與法式金邊|法式金邊]]。
3. **陪襯留白指（通常為小指）**：
   - 降低複雜度，給予視覺喘息空間。
   - 採用純色跳色、透白色薄塗或極細微珠光，確保整體平衡不壅塞。
