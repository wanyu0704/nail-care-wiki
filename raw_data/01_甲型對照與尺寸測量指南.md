# 01 甲型對照與尺寸測量指南

## 1. 軟尺測量真甲尺寸步驟
1. **測量位置**：找到甲面最寬之處（通常位於甲床中段）。
2. **軟尺貼合**：將軟尺緊貼甲面弧度，從左側甲緣量至右側甲緣。
3. **紀錄數據**：紀錄大拇指至小指之毫米數（mm），如 `15-11-12-11-8`。
4. **碼數對照**：
   - XS：14mm / 10mm / 11mm / 10mm / 7mm
   - S：15mm / 11mm / 12mm / 11mm / 8mm
   - M：16mm / 12mm / 13mm / 12mm / 9mm
   - L：17mm / 13mm / 14mm / 13mm / 10mm
*注意：若尺寸介於兩碼之間，建議「寧大勿小」，收到後可用拋光條打磨邊緣。*

## 2. 常見穿戴甲甲型特點
- **中梯形 (Medium Coffin)**：視覺拉長手指，修飾效果佳，適合歐美風格或精細繪圖。
- **杏仁型 (Almond)**：前端微尖修長，具優雅女人味，適合貓眼與暈染造型。
- **短橢圓 (Short Oval)**：貼近原生甲，日常生活方便，適合上班族與學生。
- **方形/短方 (Square / Short Square)**：個性俐落，甲面寬大好發揮繪圖創作。

## 3. 甲型修剪與適應原則
- **後緣磨合**：原生甲後緣較平者，需用砂條將穿戴甲根部磨平弧度，避免刺傷甲皮。
- **側緣修磨**：若穿戴甲側邊過寬，需傾斜 45 度打磨至完全貼合甲溝。
