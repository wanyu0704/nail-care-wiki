# 02 貓眼與油畫風配置邏輯

## 1. 貓眼膠光澤與磁吸技巧
- **寬貓眼 (Wide Cat-eye)**：使用圓形或長條磁鐵從甲面四角向中心推磁，形成面狀通透光澤。
- **斜線貓眼 (Diagonal Cat-eye)**：將條形磁鐵傾斜 45 度放置於甲面上方 3mm 處，吸出俐落光帶。
- **玻璃珠貓眼 (Glass Bead Cat-eye)**：利用柱狀磁鐵繞圈吸引，創造圓形立體光斑。

## 2. 油畫風堆疊與色彩學
- **底色打底**：選用低飽和度奶茶色、灰粉色或裸米色作為油畫打底。
- **筆觸堆疊**：使用平頭繪畫筆沾取膠體，以不規則點刷方式呈現油畫肌理感。
- **色調平衡**：同手五指色彩不宜超過 3 種主色，保持整體視覺協調。

## 3. 十指配置與主次焦點設計
- **主焦點（食指/無名指）**：配置複雜油畫、手繪圖案或 3D 立體浮雕。
- **次焦點（大拇指/中指）**：配置高透亮貓眼或法式金邊。
- **陪襯指（小指）**：採用純色跳色或極簡微珠光，避免視覺過度擁擠。

## 4. 立體裝飾與法式金邊
- **微立體雕花**：使用硬質黏鑽膠或立體浮雕膠拉出立體線條，再刷上鏡面粉。
- **法式金邊 (French Gold Edge)**：於甲尖勾勒 1mm 極細金屬鏡面線，提升精緻質感。
