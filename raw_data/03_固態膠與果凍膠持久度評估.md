# 03 固態膠與果凍膠持久度評估

## 1. 果凍膠 (Jelly Stickers) 特性與操作
- **持久度**：約 3～7 天。
- **優勢**：不傷真甲、拆卸簡單、穿戴甲可重複使用率高。
- **適合場景**：週末活動、拍攝拍照、高頻率更換造型者。
- **黏貼關鍵**：
  1. 甲面必須徹底以酒精棉片去油去水。
  2. 吹風機微熱烘烤果凍膠 3 秒增強黏性。
  3. 45 度角斜向貼合，由後緣往指尖用力按壓 30 秒排出空氣。

## 2. 固態貼片膠 / 固態膠 (Solid UV Gel) 特性與操作
- **持久度**：約 2～4 週。
- **優勢**：防水抗油、牢固度極高、貼合無縫隙。
- **適合場景**：長期佩戴、常接觸水與家事者。
- **黏貼關鍵**：
  1. 真甲表面需輕微打磨拋光增強附著力。
  2. 取適量固態膠揉成小球放於穿戴甲根部。
  3. 壓實膠體無氣泡後，使用美甲燈照燈 60 秒使其固化。

## 3. 兩者評估與比較表
| 評估項目 | 果凍膠 | 固態 UV 膠 |
| :--- | :--- | :--- |
| **持久天數** | 3 - 7 天 | 14 - 30 天 |
| **防水能力** | 中等（防短時間洗手） | 極高（可洗澡、洗碗） |
| **拆卸難易度** | 極易（櫸木棒即可推開） | 需解膠劑與耐心浸泡 |
| **甲片重複使用** | 完全不損壞甲片 | 需刮除殘膠，甲片易損耗 |
